## LanternLib
A library mod containing common functionality and some minor bug fixes to use across my mods.

### **Modpack Usage**
You may include this mod into your own modpacks.

### **Dependence**
Mod developers are free to depend on this mod without being required to open-source their own projects. The LGPL-3.0 license applies only to this mod and any modifications of it.

### **Forks & Modifications**
You may fork and modify this project. However, if you distribute a modified version, you must also provide access to the source code of your changes as per the LGPL-3.0 license.

### **If building from source**
You may notice that some files and Gradle configs are missing. This is due to the fact that this mod is being created in my [multi-mod workspace](https://github.com/RedCraft86/MCModTemplates) setup where the root Gradle files handle most of the common stuff.
